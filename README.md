# Samhita Soil Solutions

Website for Samhita Soil Solutions — Government of India certified manufacturer of organic bio-pesticides, bio-fertilizers, and micronutrients based in Kakinada, Andhra Pradesh.



## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Framer Motion
- Cloudflare Pages

## Development

```sh
npm i
npm run dev
```

## Build & Deploy

```sh
npm run build
npx wrangler pages deploy dist --project-name=samhita-soil
```
